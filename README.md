# vet

Site de pet shop e clínica veterinária (exemplo: **Amigo Fiel**). Estático, sem build:
abre direto no navegador e publica no GitHub Pages.

- Todos os dados da loja ficam em `js/config.js`.
- Como adaptar para um cliente: [PERSONALIZAR.md](PERSONALIZAR.md).

Para ver localmente: `python3 -m http.server` na pasta do projeto e abrir http://localhost:8000.
